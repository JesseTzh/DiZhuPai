# 扑克牌美术资源

本目录是扑克牌美术的唯一源码入口，不依赖 DOM、三维引擎或交互状态。场景和独立 SVG 都使用同一套绘制函数。

| 文件            | 内容                                     |
| --------------- | ---------------------------------------- |
| `palette.js`    | 纸色、墨色、红蓝金绿印色与纸边材质       |
| `primitives.js` | 印刷路径、圆形辅助函数                   |
| `suits.js`      | 四种花色的矢量轮廓与双向角标             |
| `pips.js`       | A–10 的点数布局；红桃 7 保留原版布局     |
| `king.js`       | 原版国王半身画像及花色配色               |
| `courts.js`     | J/Q/K 的双头画像、服饰与裁剪框           |
| `jokers.js`     | 大小王的小丑、帽铃与拼色服装             |
| `back.js`       | 彩色织纹与中心斑驳金币牌背               |
| `deck.js`       | 54 张牌的稳定 key、顺序、类型与名称      |
| `index.js`      | 统一牌面导出及独立 SVG 封装              |
| `svg/`          | 生成的 54 张牌面、5 张牌背，每张一个 SVG |
| `preview.html`  | 可离线打开的完整美术总览                 |

在项目根目录运行 `npm run assets:cards` 更新 SVG 和总览；`npm run build` 同时更新资源与离线场景。不要直接修改生成文件。开发服务器中访问 `/assets/cards/preview.html`。

统一坐标为 `viewBox="0 0 63 88"`。牌面暖纸底由场景或 SVG 封装提供，绘制函数只返回印刷层。四种花色均为路径，不依赖花色字体；角标使用系统衬线字体。J/Q/K 上下旋转 180° 对称，裁剪 ID 以每张牌的 key 隔离。SVG 导出使用场景相同的印刷线宽系数。

牌组顺序：红桃 A–K、黑桃 A–K、方块 A–K、梅花 A–K、小王、大王。数字牌组包含 A，共 40 张；人头牌 J/Q/K 共 12 张；王牌单独 2 张。黑桃 K 持剑、Q 持花、J 持戟；各花色采用不同的主袍配色。
