# 道具美术资源与代码组织规范化

## 现状结论（已确认）

每个道具（frog/hand/dragon）现有 **2 份程序化美术**：① 3D 玩具模型（商店柜台 + 游戏桌面共用，`shop/toys.js` + `toy-dragon.js` + `toy-palettes.js`）② 2D 顶栏 canvas 图标（`ui/topbar-art.js` 的 icons 字典）。主要问题：新增一个道具要改 7+ 个文件，且有大量 `id === 'dragon'` 三元特判和按数组下标的摆放硬编码散落在 scene.js、timelines.js、table-items.js、state.js、save.js。

**目标**：新增道具只做两件事——新建一个美术模块文件 + 在注册表加一行；消费方（商店/桌面/顶栏/规则）全部自动跟随。

## 改动清单

### 1. 移动 `src/shop/stage3d.js` → `src/engine/stage3d.js`
3D 网格图元库（orb/rod/slab/tube），只依赖 `engine/math.js` + `engine/palette.js`，移入 engine 合法（架构测试允许）。更新 7 个 shop 文件的 import 路径（scene/goose/goose-ledger/counter/room/exit-path/timelines）。

### 2. 新建 `src/assets/items/`（仿 `src/assets/cards/` 先例）
```
src/assets/items/
  README.md     新增道具规范 + checklist
  palettes.js   ← 移自 shop/toy-palettes.js（原样）
  frog.js       一文件一道具：build(3D模型) + REST + tablePose + duration
                + pose(t)(展示动画) + icon(顶栏图标) + shop{摆放/底座/价签/收回时长}
                + table{桌面 u,v 坐标}
  hand.js       同上
  dragon.js     同上（toy-dragon.js 内容并入）
  index.js      注册表 TOYS + model(map) 工厂 + buildToy/toyGeometry(缓存)
                + toyPose/blend + 聚合 REST + 导出 SLOTS
```
桌面摆放改为每道具显式坐标（frog u:-337,v:242 / hand u:-307,v:236 / dragon u:-277,v:242，由现有数组换算，视觉零变化），替换 `[-22,8,38][slot]` 下标硬编码（第 4 个道具会直接 NaN）。商店展台配置数据化，替换 scene.js 中 4 处 `id === 'dragon'` 三元。每个文件 ≤400 行（架构测试约束）。

### 3. 删除 `shop/toys.js`、`shop/toy-dragon.js`、`shop/toy-palettes.js`

### 4. 消费方更新
- `shop/scene.js`：改从 assets/items 导入；stand()/priceAt/收回时长读注册表配置
- `shop/timelines.js`：toyPose/TOY_TIME/blend 移出，只留鹅掌柜购买动画
- `game/table-items.js`：toyGeometry 改从 assets/items 导入，摆放读 per-item 配置
- `ui/topbar-art.js`：icons 字典只留关卡图标（头巾/礼帽/皇冠/金币），道具图标从注册表取

### 5. 规则接线数据化
- `game/items.js`：每道具加 `rule` 字段（frog→wildCard, hand→looseTriple, dragon→shortStraight），导出 `hasItemRule(game, rule)` 助手
- `game/state.js:56` 与 `ruleOptions()`、`game/save.js:71`：`includes('frog'/'hand'/'dragon')` 硬编码全部改为按 rule 字段推导，行为不变

### 6. 测试与文档
- `tests/camera-items.test.mjs`：硬编码的 `['frog','hand','dragon']` 改为从 ITEMS 推导（新道具自动纳入覆盖）
- `assets/items/README.md` 写明：目录职责、每个文件的字段契约、toy units 坐标约定、pose 必须以静止姿势收尾、`.toy-<id>` CSS 约定、新增道具 checklist；记录两处已知联动不做重构——赖子牌美术（`assets/cards/wild.js` 青蛙主题）与 SVG 滤镜 id 撞名陷阱
